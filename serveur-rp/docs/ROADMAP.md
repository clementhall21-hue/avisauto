# Roadmap — de zéro au serveur qui compte

## Phase 0 — Fondations (maintenant → ~1 mois)

**Objectif : un serveur de dev qui tourne, un concept verrouillé.**

- [x] Choix du concept : crime organisé
- [x] Structure du projet, stack technique (QBCore + txAdmin + MariaDB)
- [ ] Serveur de dev en ligne (VPS ~10-20 €/mois, 8 Go RAM mini)
- [ ] QBCore installé + configuré, base de données opérationnelle
- [ ] Prototype jouable de `av-territories` (3 zones de test)
- [ ] Nom du serveur + identité visuelle (logo, charte)
- [ ] Discord monté (règlement, candidatures whitelist, tickets)

## Phase 1 — Bêta fermée (mois 2-3)

**Objectif : 30-50 joueurs whitelist qui testent et s'attachent.**

- [ ] Scripts crime de base : drogues (chaîne complète), armes marché noir, blanchiment v1
- [ ] Système de gangs : création, hiérarchie, trésorerie
- [ ] `av-territories` complet : influence, revenus, guerres encadrées
- [ ] Police jouable avec un staff dédié
- [ ] Recrutement des premiers modérateurs (les meilleurs joueurs de la bêta)
- [ ] Premiers braquages custom

## Phase 2 — Lancement public (mois 4-6)

**Objectif : 100-200 joueurs simultanés, premiers streamers réguliers.**

- [ ] Whitelist ouverte avec entretiens
- [ ] Programme streamers : onboarding VIP, support prioritaire, pas de file d'attente
- [ ] Site web : carte des territoires en temps réel, stats des gangs, candidatures
- [ ] Monétisation Tebex activée (priorité de queue + cosmétiques uniquement)
- [ ] Événements scénarisés mensuels
- [ ] Clips/moments forts postés sur TikTok/YouTube Shorts (la vraie pub, gratuite)

## Phase 3 — Croissance (mois 6-12)

**Objectif : devenir un nom qui compte dans le RP FR.**

- [ ] 2-3 streamers "locomotive" installés sur le serveur
- [ ] Contenu exclusif renouvelé chaque mois (le RP crime s'use vite)
- [ ] Équipe dev élargie (recruter dans la communauté)
- [ ] Trésorerie serveur saine : les revenus Tebex financent infra + dev

## Phase 4 — GTA 6 (dès ouverture de l'écosystème, 2027+)

**Objectif : être parmi les premiers serveurs GTA 6 FR crédibles.**

- [ ] Veille active sur le support FiveM/CFX pour GTA 6
- [ ] Port des scripts custom (l'architecture est pensée pour : logique métier séparée des appels natifs GTA 5)
- [ ] Migration de la communauté existante = longueur d'avance énorme sur les serveurs qui partent de zéro
- [ ] Le lore continue : la ville change, l'histoire des gangs se poursuit → les joueurs migrent avec leur passé

## Les métriques qui comptent

| Métrique | Bêta | Lancement | Croissance |
|----------|------|-----------|------------|
| Joueurs simultanés (soirée) | 30+ | 100+ | 300+ |
| Rétention 30 jours | 50 % | 40 % | 40 % |
| Streamers réguliers | 0 | 2-3 | 5+ |
| Heures Twitch/mois sur le serveur | — | 500+ | 5000+ |
